## Stack del sitio

- HTML, CSS y JavaScript sin build step.
- Tipografías Space Grotesk, Inter y JetBrains Mono.
- Diseño oscuro responsive, animaciones de entrada y tarjetas por proyecto.
- GitHub Pages sirviendo desde `main` en la raíz del repositorio.

## Desarrollo local

```bash
python3 -m http.server 8000
# abrir http://localhost:8000
```
